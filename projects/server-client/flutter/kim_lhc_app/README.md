# kim_lhc_app

運行 KIM LHC 判斷的應用程式。

## Packages

1. camera: ^0.11.0+1
   - 需要在 `android\app\build.gradle` 中新增 `minSdkVersion 21`
2. chunked_uploader: ^1.1.0
3. dio: ^5.4.3+1
4. format: ^1.5.2
5. path_provider: ^2.1.3
6. video_player: ^2.8.6

## 開發套件

1. flutter_launcher_icons: ^0.13.1
   - 使用 `flutter pub run flutter_launcher_icons` 指令生成應用程式圖標
