# 時間評級

尋找可以幫助自動化、簡化或優化工作流程的技術解決方案

- 1~3: 無建議
- \>=3.5: 頻率較高，需看情況調整工時或穿戴護具。
- \>=7:頻率過高，必須調整工時，或進行檢查。

# 負重

可以讓兩個人一起搬運，以降低單人負重，或將貨物分裝，以減少單件貨物的重量。

# 力量傳遞 / 負重條件

工作中應盡量平均地施力，防止其中一測施力過重造成危害

# 身體姿勢

- 姿勢評級

- 額外加分
  1.  保持軀幹穩定：嘗試通過轉動腳步而不是腰部來改變方向，這樣可以減少軀幹的扭轉和側傾。
  2.  保持物體靠近身體：搬運物品時，盡量讓物品靠近身體，避免過度伸展手臂。
  3.  規劃工作動線：重新規劃工作路徑和流程，盡量減少手臂抬舉的次數和時間。
  4.  使用工具：讓你可以在較低的位置進行操作，減少手臂高過肩膀的情況。

# 不良工作條件

1. 手/手臂的位置與動作
   - 調整工作姿勢，避免發生達到關節活動範圍極限的動作。
2. 力量傳遞 / 應用受限
   - 使用防滑手套、安裝輔助工具、調整工作姿勢與高度。
3. 不良的氣候條件
   - 熱或不舒服的吹風的狀況-可以安裝空調或風扇。
4. 寒冷或潮濕的狀況
   - 可以增加保暖或防水措施。
5. 受限的空間條件
   - 調整工作流程或重新安排工作場地還有進行場地的清潔與維修。
6. 衣服
   - 可以選擇輕便舒適的防護裝備。
7. 搬運/握持困難
   - 增加人員協助或使用搬運車。

# 工作協調 / 時間分佈

與主管或同事討論工作安排，聽取意見和建議，及時調整工作計劃。

# 結果評級演算法

這三項是你在評測中得分較高的項目（但仍可改進），其百分比計算方式為：該項評測得分 / 總分。

These three items are the ones where you scored higher in the assessment (but still need improvement). The percentage calculation is: score for this item / total score.
